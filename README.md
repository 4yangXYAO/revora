# Revora Portofolio Web

This is a Next.js project bootstrapped with `create-next-app` and styled with Tailwind CSS.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
`
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
